# Oceano Vivo – ODS 14

Este projeto é um website desenvolvido em **Streamlit** com o objetivo de promover a conscientização sobre a **ODS 14 – Vida na Água**.

O site permite:
- Informar sobre a importância dos oceanos
- Apresentar ameaças ambientais
- Cadastrar ações sustentáveis realizadas por usuários
- Consultar e analisar os dados cadastrados

# Tecnologias utilizadas
- Python
- Streamlit
- SQLite
- Pandas

# Objetivo
Promover o uso sustentável dos oceanos por meio de informação, interatividade e participação do usuário.
